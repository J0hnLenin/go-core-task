# Go Core Task

Репозиторий с выполненными тестовыми заданиями по языку Go. Здесь собраны небольшие задачи, покрывающие базовые возможности языка.

## 📁 Структура проекта

```
go-core-task/
├── 1/          # Задание 1
├── 2/          # Задание 2
├── 3/          # Задание 3
├── 4/          # Задание 4
├── 5/          # Задание 5
├── 6/          # Задание 6
├── 7/          # Задание 7
├── 8/          # Задание 8
├── 9/          # Задание 9
├── go.mod      # Файл модуля Go
├── go.sum      # Контрольные суммы зависимостей
└── task.md     # Описание всех заданий
```

Каждая папка содержит решение соответствующей задачи и, при необходимости, модульные тесты.

## 🚀 Быстрый старт

### Требования

- Установленный Go (рекомендуется последняя стабильная версия)

### Клонирование репозитория

```bash
git clone https://github.com/J0hnLenin/go-core-task.git
cd go-core-task
```

### Запуск тестов

Перейдите в папку с заданием и выполните:

```bash
cd 1
go test -v
```

Либо запустите все тесты сразу из корня проекта:

```bash
go test ./...
```

## 🛠️ Используемые технологии

- **Go** — все решения написаны на чистом Go без сторонних библиотек
- **Стандартный пакет `testing`** — для написания и запуска юнит-тестов

## 📦 Управление зависимостями

Проект использует Go Modules. При необходимости подтянуть зависимости:

```bash
go mod tidy
```
